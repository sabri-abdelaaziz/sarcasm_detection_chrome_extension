ICON FILES NEEDED
=================

The extension requires three icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

You can:
1. Create these icons using any image editor
2. Use online icon generators
3. Temporarily remove icon references from manifest.json to test without icons

Quick solution: Create a simple colored square with "SD" text for Sarcasm Detector.
